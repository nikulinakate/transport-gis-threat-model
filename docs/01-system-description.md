# 1. Описание информационной системы

## 1.1. Назначение

Условная государственная информационная система транспортного мониторинга предназначена для приёма, обработки, хранения и предоставления сведений о дорожной обстановке.

К основным функциям относятся:

- получение транспортных событий от внешних источников;
- нормализация и проверка поступивших данных;
- отображение событий на автоматизированных рабочих местах операторов;
- хранение истории событий и действий пользователей;
- передача сведений во внешние информационные системы;
- формирование статистической и оперативной отчётности.

## 1.2. Состав компонентов

В демонстрационной архитектуре выделены:

1. Внешний интеграционный шлюз.
2. Сервер приложений.
3. Сервер базы данных.
4. Веб-интерфейс оператора.
5. Автоматизированные рабочие места администраторов.
6. Система централизованного журналирования.
7. Средства резервного копирования.
8. Средства межсетевого экранирования и защиты веб-приложений.
9. Сегмент администрирования.
10. Внешние информационные системы и источники данных.

## 1.3. Границы моделирования

В границы моделирования включены серверные компоненты, рабочие места пользователей, сетевые соединения, программные интерфейсы, средства администрирования, журналы событий, резервные копии и используемые учётные записи.

Не включены физические процессы управления дорожным движением, оборудование сторонних организаций, а также телекоммуникационная инфраструктура операторов связи за пределами точек подключения к системе.

## 1.4. Зоны доверия

- внешняя сеть;
- зона публикации сервисов;
- прикладной серверный сегмент;
- сегмент баз данных;
- пользовательский сегмент;
- сегмент администрирования;
- контур средств защиты и мониторинга.

Переход между зонами допускается только через контролируемые сетевые соединения. Административный доступ должен выполняться из выделенного сегмента с применением усиленной аутентификации и регистрацией действий.

## 1.5. Основные потоки данных

| Поток | Источник | Получатель | Содержание |
|---|---|---|---|
| F-01 | Внешний источник | Интеграционный шлюз | Транспортные события |
| F-02 | Интеграционный шлюз | Сервер приложений | Проверенные сообщения |
| F-03 | Сервер приложений | База данных | События, справочники, учётные данные |
| F-04 | Рабочее место оператора | Сервер приложений | Запросы и управляющие действия |
| F-05 | Компоненты системы | Система журналирования | События безопасности |
| F-06 | Серверы | Система резервного копирования | Резервные копии данных и конфигураций |

## 1.6. Допущения

- система размещена в контролируемой зоне;
- межсетевое взаимодействие выполняется по утверждённой схеме;
- пользователи имеют персональные учётные записи;
- действия администраторов регистрируются;
- программное обеспечение обновляется в рамках установленного процесса управления изменениями;
- фактический класс защищённости и категория значимости в проекте не устанавливаются.
