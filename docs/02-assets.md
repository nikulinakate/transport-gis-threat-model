# 2. Объекты воздействия и негативные последствия

## 2.1. Подход к идентификации активов

Объекты воздействия определены по результатам декомпозиции функций системы, потоков данных, программно-технических компонентов и ролей пользователей.

Для каждого объекта учитываются возможные нарушения конфиденциальности, целостности и доступности, а также влияние на выполнение функций системы.

## 2.2. Основные информационные ресурсы

| Код | Объект | Назначение | Критичные свойства |
|---|---|---|---|
| A-01 | Транспортные события | Хранение сведений о дорожной обстановке | Целостность, доступность |
| A-02 | Учётные записи | Идентификация пользователей и сервисов | Конфиденциальность, целостность |
| A-03 | Ролевые назначения | Разграничение полномочий | Целостность |
| A-04 | Журналы безопасности | Контроль и расследование событий | Целостность, доступность |
| A-05 | Конфигурации компонентов | Настройка серверов, сетей и средств защиты | Конфиденциальность, целостность |
| A-06 | Интеграционные ключи | Аутентификация межсистемных соединений | Конфиденциальность, целостность |
| A-07 | Резервные копии | Восстановление данных и конфигураций | Конфиденциальность, целостность, доступность |
| A-08 | Прикладное программное обеспечение | Реализация функций системы | Целостность, доступность |

## 2.3. Технические объекты

- серверы приложений;
- серверы баз данных;
- интеграционный шлюз;
- автоматизированные рабочие места;
- сетевое оборудование;
- средства защиты информации;
- средства резервного копирования;
- система централизованного журналирования;
- каналы связи и программные интерфейсы.

## 2.4. Возможные негативные последствия

| Код | Последствие |
|---|---|
| C-01 | Искажение сведений о дорожной обстановке |
| C-02 | Недоступность функций мониторинга и отображения событий |
| C-03 | Выполнение действий от имени легитимного пользователя |
| C-04 | Несанкционированное изменение конфигурации системы |
| C-05 | Нарушение межсистемного взаимодействия |
| C-06 | Утрата возможности установить последовательность действий при расследовании |
| C-07 | Раскрытие служебной информации и параметров защиты |
| C-08 | Распространение вредоносного программного обеспечения внутри контура |
| C-09 | Невозможность восстановления после сбоя или инцидента |

## 2.5. Критерии значимости

При оценке последствий учитываются:

- продолжительность нарушения функций;
- количество затронутых пользователей и компонентов;
- возможность принятия ошибочных управленческих решений;
- объём потерянных или искажённых данных;
- влияние на смежные системы;
- сложность обнаружения и восстановления;
- возможные регуляторные и репутационные последствия.
